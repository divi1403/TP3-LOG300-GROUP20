
# GITHUB DOCS

## INFORMATION DE BASE DU PROJET

 * Nom du projet :   Calculatrice Flash
 * Numero d'équipe :  20


### Objectif 
Développer et structurer une application web de calculatrice.


### Prérequis

 * Git installé localement
 * Python (Dernière Version recommandée) et pip installés

### Dépendances à installer
Ce projet repose sur Flask pour l'exécution du serveur web backend

### Instruction pour installer les dépendances 

pip install Flask si le fichier requirements.txt est absent sinon pip install -r requirements.txt
